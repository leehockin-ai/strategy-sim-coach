# Assessment notices and custom practice — preview delivery

> Custom practice follow-up: implementation and storage design below are superseded by `private-practice-launch-verification.md` and `unapplied/private-practice-launch.sql`. Hosted Start still fails closed pending isolated schema installation. Email remains unchanged.

## What works now
- Scenarios has a collapsed **Create your own scenario to coach** intake. Paste client-safe text or extract PDF/TXT/MD/VTT/SRT in memory; review/edit the brief, team, public tensions, scope, outcome, constraints and coaching challenge generated through authenticated Lovable AI.
- Limits: 4 MB, PDF 50 pages, selectable text only, first 24,000 characters. No OCR, Word or audio transcription. Source type/content is validated server-side. PDF extraction reuses `unpdf` from the existing authorized playbook extractor, without its storage upload.
- Source text is untrusted; marked private sections are omitted before AI input, hidden criteria/system fields are not in the output schema. The coach must redact confidential/private material and confirm client-safe input. This is not a guarantee that AI can detect every unmarked secret. Drafts are provisional and require review.
- Drafts are transient React state, not localStorage or database rows; raw file bytes are discarded and pasted source is cleared on successful draft generation. Failed generation preserves input for explicit retry. No automatic retry or source logging added.
- Successful new assessment insertion calls one scenario-independent completion boundary. Reports and initial intake now truthfully state that email is unconfigured and no email has been sent. Existing assessments are not scheduled or changed on read.
- Pure mail contract contains a trusted signed-in report URL, verified-owner recipient identity contract and review-status text only, no scores, report body, source or scenario payload. Mock dispatcher uses a durable lease/CAS contract and the same key on retry; queued is never called delivered.

## Explicitly unavailable in hosted preview
**Custom practice Start is disabled and its server entry point always refuses.** There is no safe owner-private durable scenario/session storage yet. Existing `scenarios` SELECT policy permits all authenticated users and admin-backed listing projects public columns; inserting custom rows there would leak private content. No workaround, public custom row or fake hosted launch was created.

The full Scope → Approach → Chapter 2 → Chapter 3 → nine-dimension custom practice/report journey is therefore NOT implemented or verified on hosted storage. No custom attempt enters certification counts or review because no custom attempt can start. Seeded journey behavior and all existing team handlers are unchanged.

**No email sender, template, queue or delivery adapter is active.** The new completion boundary currently returns unconfigured. The durable transactional outbox is a prepared design, not installed persistence. Thus production durable one-per-assessment delivery is NOT claimed.
